# Technical Analysis Workflow in Python using the LSEG Data Library for Python
 
In this workflow I create technical analysis triggers without needing to use charts and visually identify signals with the LSEG Data Library for Python.

**Pre-requisites:**  

LSEG Workspace.

Python wrapper <a href="https://github.com/TA-Lib/ta-lib-python" target="_blank">ta-lib</a> - for the Technical Analysis Library - <a href="https://ta-lib.org/" target="_blank">TA-Lib</a>
